# Bitcoin Price Forecasting with BiGRU and Indonesian News Sentiment
Hybrid deep learning model that integrates historical market data with Indonesian financial news sentiment to forecast Bitcoin's daily closing price. Originally developed as an undergraduate thesis (Institut Teknologi Sepuluh Nopember) and adapted into a paper submitted to ICoDMI 2026 (International Conference on Data Science, Mathematics, and Informatics).

## Overview
Bitcoin's extreme volatility makes accurate price forecasting difficult using historical price data alone. This project tests whether combining three types of signal improves forecasting accuracy:

1. **Technical data** — Bitcoin's own historical price and trading volume
2. **External market factors** — GLD (gold), S&P 500, and NASDAQ 100 closing prices
3. **News sentiment** — daily sentiment extracted from 8,800+ Indonesian-language crypto news articles using a pretrained financial sentiment transformer ([Indo RoBERTa Financial](https://huggingface.co/ihsan31415/indo-roBERTa-financial-sentiment))

Three Bidirectional GRU (BiGRU) model configurations are trained and compared to isolate the effect of each signal type.

## Results

| Model | Features | MAPE | RMSE (USD) |
|---|---|---|---|
| Technical | BTC price + volume | 2.02% | $1,885.03 |
| **External-Factor** | + GLD, S&P 500, NASDAQ 100 | **1.90%** | **$1,810.57** |
| Hybrid | + news sentiment (D1–D4) | 2.71% | ~$2,483 |

The external-factor model performed best. Adding sentiment features did **not** improve accuracy — likely due to class imbalance in the labeled news data (dominated by neutral articles) and moderate sentiment-classifier accuracy (75% on manual validation). This negative result is discussed in the paper as an important finding, not just a footnote.

> **Note on evaluation scope:** results reflect a single training run per configuration; no naive-baseline comparison, multi-seed replication, or formal significance testing was performed. See [Limitations](#limitations) below.

## Pipeline

```
News scraping (Detik, CNBC Indonesia, Tokocrypto)
        │
        ▼
Preprocessing & deduplication ──► Sentiment labeling (Indo RoBERTa Financial)
        │                                   │
        ▼                                   ▼
Market data (BTC, GLD, S&P500, NASDAQ)   Daily sentiment aggregation (D1–D4)
        │                                   │
        └───────────────┬───────────────────┘
                         ▼
              Feature alignment (30-day window)
                         ▼
        BiGRU (2-layer, 128+64 units) — 3 configurations
                         ▼
         Evaluation: MAPE, RMSE, MAE, sMAPE, directional accuracy
                         ▼
                  SHAP feature importance
```

## Repository Structure

```
.

├── ICoDMI_paper.pdf             # conference paper
├── requirements.txt
├── .gitignore
└── README.md
```

The pipeline is kept as a single notebook (sectioned with markdown headers) rather than split into separate modules, since the project is small enough that one well-organized notebook is easier to follow end to end than jumping between files. Raw data, model checkpoints, and generated CSVs/images are excluded via `.gitignore` and regenerated by running the notebook.

## Tech Stack

- **Modeling:** TensorFlow / Keras (Bidirectional GRU), statsmodels (ARIMA baseline)
- **NLP:** Hugging Face Transformers, PyTorch (Indo RoBERTa Financial)
- **Data collection:** Requests, BeautifulSoup
- **Analysis:** pandas, NumPy, scikit-learn, SHAP
- **Visualization:** Matplotlib, Seaborn

## Getting Started

```bash
git clone https://github.com/alesandroyoel/Forecasting-Bitcoin-BiGRU-Sentiment.git
cd Forecasting-Bitcoin-BiGRU-Sentiment
pip install -r requirements.txt
```

Open `Bitcoin_Forecasting.ipynb` and run top to bottom. Web scraping is disabled by default (`RUN_SCRAPING = False`) — provide your own CSV data or enable scraping in the config cell (Section 0).

## Data

- **Market data:** daily closing prices for BTC, GLD, S&P 500, NASDAQ 100 (Jan 2024–Sep 2025), sourced from Investing.com
- **News data:** 8,800+ articles from Detik.com, CNBC Indonesia, and Tokocrypto, collected via keyword-based web scraping

Raw data is not included in this repository (file size / terms of use) — see `.gitignore`. The scraping, preprocessing, and sentiment-labeling functions in the notebook can reproduce the dataset from scratch.

## Limitations

- Single training run per model configuration (no multi-seed variance estimate)
- No naive-persistence or classical statistical baseline included in the original comparison
- No formal statistical significance testing between model MAPE/RMSE values
- Sentiment classifier validated on a small manually-labeled sample (~440 articles, 75% accuracy)
- News corpus limited to three Indonesian-language outlets
